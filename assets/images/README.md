# Artwork assets

Place original, rights-cleared source artwork here in theme-specific folders:

- fruit/
- flowers/
- toys/
- birds/
- animals/
- professions/

The review sample can be generated from 12 built-in, deterministic motifs per theme. For a 100-page volume, supply exactly 50 approved, distinct artwork files in the corresponding theme folder. The loader will refuse partial sets, repeated pixel-identical art, and colored source images. Transparent backgrounds are flattened onto white; anti-aliased grayscale is thresholded to pure black/white.

Use PNG, JPG, or JPEG source images. The final PDF preflight measures effective DPI at the actual placed size. Each image must be original or accompanied by documented commercial-use rights. Do not add logos, licensed characters, branded toy designs, or artwork copied from search results. Near-duplicate artwork still requires human visual review.
